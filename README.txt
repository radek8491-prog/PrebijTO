PŘEBIJ TO – web pro Firebase Hosting nebo GitHub Pages

Obsah:
index.html – aktuální web včetně přepínání jazyků
firebase.json – konfigurace Firebase Hosting
.nojekyll – GitHub Pages

Firebase: rozbalit ZIP, v terminálu ve složce projektu spustit firebase deploy --only hosting (vyžaduje přihlášení a inicializovaný Firebase projekt).
GitHub Pages: nahrát soubory do kořene repozitáře, Settings > Pages > Deploy from a branch, vybrat main / (root).

Přímé APK: https://github.com/radek8491-prog/PrebijTO/releases/download/v1.0.0/PrebijTO.apk
Poznámka: ZIP obsahuje poslední dostupnou verzi webu. Návody v některých jazycích stále nejsou plně přeložené a přesné původní snímky všech 35 obrazovek nebyly do této verze doplněny.
